KnoxMap - how to set it up and make your first map
==================================================

KnoxMap turns a real place into a Project Zomboid Build 42 map. You draw a
box on a map of the world, press four buttons, and the town appears in your
game with its real streets and its real buildings, furnished inside.

This file is the long way round. If you just want to get going: run Setup,
run KnoxMap, draw a box, press the four buttons in order.


WHAT YOU NEED FIRST
-------------------

* Project Zomboid, BUILD 42. Build 41 cannot load these maps. In Steam:
  right-click the game, Properties, Betas, pick the Build 42 branch.
  Start the game once after switching, so Steam finishes the download.

* Windows: nothing else. Everything comes with KnoxMap.

* Linux: 64-bit Python 3.10 or newer. Most distributions have it already;
  if not, install python3 and python3-venv from your package manager.

* macOS: 64-bit Python 3.10 or newer, and Wine. Wine is only needed for
  the Compile step - everything else works without it.

You do NOT need to download the map tools or any tile artwork yourself.
Setup fetches the tools and takes the artwork out of your own copy of the
game. Nothing comes from anyone else's copy.


STEP 1 - UNPACK IT
------------------

Windows   Right-click the .zip, Extract All. Put the folder somewhere you
          can write to - your Documents, say. Not Program Files.

Linux     tar -xzf KnoxMap-*-linux.tar.gz
macOS     tar -xzf KnoxMap-*-macos.tar.gz

Keep the whole folder together. KnoxMap keeps your maps inside it.


STEP 2 - RUN SETUP (once)
-------------------------

Windows   Double-click Setup.bat
Linux     ./setup.sh
macOS     ./setup.sh

It prints five steps and takes a few minutes, mostly downloading the map
tools and pulling the tile artwork out of your game. Leave it running.

If it cannot find Project Zomboid it will ask you to paste the path. Any of
these is fine - the Steam library, the ProjectZomboid folder, or the media
folder itself:

  Windows   C:\Program Files (x86)\Steam\steamapps\common\ProjectZomboid
            or D:\SteamLibrary\steamapps\common\ProjectZomboid

  Linux     ~/.steam/steam/steamapps/common/ProjectZomboid
            or ~/.local/share/Steam/steamapps/common/ProjectZomboid

  macOS     The game is inside an application bundle, so the folder you
            want is deeper than you might expect. This prints it:

              find ~/Library/Application\ Support/Steam -type d -name texturepacks

            Paste what that prints, or anything above it. All of these work.

If Steam keeps your games on another drive, put that drive or folder in the
box under "Steam libraries" in the KnoxMap window and Setup will find it
next time.


STEP 3 - OPEN THE WINDOW
------------------------

Windows   Double-click KnoxMap.exe
          (Windows will warn about an unsigned program the first time:
          More info, then Run anyway. KnoxMap.bat does the same thing if
          you would rather read what you are running.)
Linux     ./knoxmap.sh
macOS     ./knoxmap.sh

A window opens on Home. If anything is still missing, a bar at the top
says "Setup isn't finished", with what to do about it.


STEP 4 - CHOOSE A PLACE
-----------------------

On Home, type a place in the big search box - your street and house
number, a town or a city - and press Enter. Pick it from the list. Use
the "outline" button on a result to take its real boundary instead of a box
around it.

Or draw your own: pick the Area tool on the left, then the rectangle,
polygon, circle or freehand button on the map's left edge.

Watch the Properties panel on the right as you do. It tells you how big the
map will be in tiles and cells, how much memory and time it needs, and how
much of the limit you are using. If it says you are over the limit, either
draw a smaller area or change Scale to 2 m per tile.

A good first map is a small town, or a few streets of a city - roughly one
to two kilometres across. A whole city takes hours and a lot of memory.
Start small; you can always make a bigger one afterwards.


STEP 5 - ONE BUTTON, FOUR STEPS
-------------------------------

Above the map is a row of steps, and one big button at its right end. It
always does whatever comes next, so you can just keep pressing it. Click a
step's name to see more about it.

  1. Generate map   Downloads the area from OpenStreetMap and draws the
                    ground: roads, pavements, rivers, woods, railways.
                    Seconds to a few minutes.

  2. Buildings      Turns every building outline into a real building with
                    rooms, furniture, doors and windows. A minute or so.

  3. Compile        Turns all of that into the files the game loads. This
                    is the slow one - minutes for a town. You can press
                    Stop and come back to it; nothing is lost.

  4. Install        Copies the finished map into your mods folder.

While anything is running, the big button says Stop. It stops the work and
leaves your drawn area and settings alone, so pressing it again starts the
same map over.

Every map you open gets a tab, like in a browser. The x closes it; the
other button pops it out into its own window.


STEP 6 - PLAY IT
----------------

Start Project Zomboid. In the mods list, turn on the mod named after your
map. Start a NEW save - an existing save will not have the new land in it.
Your town appears as its own starting region in the map list.

Press M in game for the paper map.


IF SOMETHING GOES WRONG
-----------------------

The window has a "report a problem" link at the top (and in the Help
menu). It gathers the log
and a description of your PC, with your name taken out of the file paths,
so somebody can see what happened.

Common things:

  "Setup isn't finished"      Read what it says underneath - it names the
                              one thing that is missing and how to fix it.

  Build 41 warning            Your game is on the wrong branch. See the
                              top of this file.

  Compile does nothing        On macOS it needs Wine. Without it every
                              other step still works, and you can finish
                              the map by hand: Open in WorldEd, then
                              BMP To TMX > All Cells, then
                              Generate Lots > All Cells, then Install.

  Out of memory               The map is too big for your PC. Draw a
                              smaller area, or set Scale to 2 m per tile.

Ask in the Discord: https://discord.gg/ePM8dSxPm7
Or open an issue: https://github.com/spytheeuclidean-a11y/knoxmap/issues


A FEW THINGS WORTH KNOWING
--------------------------

* Your maps live in the output folder inside KnoxMap. Updating KnoxMap
  never touches them.

* Opening a map again from "Your maps" on Home lets you rerun any step
  without drawing the area again.

* The window speaks English, Português (Brasil), Русский, Español and
  Türkçe: pick one from the globe at the top.

* Optional mods that make maps nicer, if you subscribe to them on the
  Workshop: Erika's Tiles (glass shop fronts and street signs), Elevators
  (working lifts in tall buildings), Spawn Selector (start at any
  landmark). KnoxMap uses them if they are there and works without them.

* Map data is OpenStreetMap's, under the ODbL. Every map you make carries
  that credit, and you keep it if you share the map.

* The insides of buildings are invented. KnoxMap knows a building's
  outline, its height and what it is for - it does not know anyone's
  actual house.
